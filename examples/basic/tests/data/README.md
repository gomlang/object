The four `.bin` samples and `reference.tsv` are generated by `generate.go` using Go 1.26 `debug/elf`. Each sample has one load segment, `.text`, `.symtab`, `.strtab`, `.shstrtab`, and two named symbols. The generator prints the Go parser's results as tab-separated rows.

The `reloc{32,64}{le,be}.bin` fixtures are separately struct-packed by
`elf/tests/data/make_relocations.py`. They contain generic ABI REL and RELA
sections, a null symbol plus one ordinary symbol, and signed addend extrema.
`go run elf/tests/data/check_relocations.go` (from the library root) independently
checks them through Go `debug/elf` and `encoding/binary`.

`dynamic{32,64}{le,be}.bin` contain independently struct-packed SHT_DYNAMIC and
PT_DYNAMIC views, repeated library references, SONAME/search-path strings,
an unknown signed tag and entries following DT_NULL. Regenerate with
`python3 elf/tests/data/make_dynamic.py`; cross-check the logical table with
`go run elf/tests/data/check_dynamic.go` from the library root.

`versions32{le,be}.bin` and `versions64{le,be}.bin` exercise GNU verdef,
verneed and versym metadata with a base definition, an inherited definition,
two imported versions, hidden symbols and an unversioned global. They are
independently packed by `elf/tests/data/make_versions.py`, which writes matching
library and public-consumer copies. `elf/tests/data/check_versions.go` checks
these vectors against Go 1.26+ `debug/elf`.
